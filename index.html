Thesis Research

Performance Comparison of CoAtNet-0 and EfficientNet-B0 Architectures in Corn Leaf Disease Classification

  • Compared two deep learning architectures for classifying corn leaf diseases into four classes using a dataset of 4,354 images
  • Built EfficientNet-B0 via transfer learning with ImageNet pretrained weights, and CoAtNet-0 from scratch combining convolution and self-attention blocks
  • Evaluated model performance using classification metrics (precision, recall, F1-score) and confusion matrix analysis
  • Conducted an out-of-distribution robustness test using 1,143 irrelevant background images to assess real-world reliability
  • Achieved 97.31% testing accuracy with EfficientNet-B0, outperforming CoAtNet-0 (94%)
